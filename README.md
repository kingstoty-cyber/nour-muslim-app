# نور المسلم

واجهة عربية متجاوبة للمصحف والأذكار والتلاوات، مستوحاة من تصميم المستخدم، بأربع صور محلية عالية الدقة (1599×900) وألوان كحلية وذهبية.

## التشغيل

```bash
npm start
```

افتح `http://localhost:3000`. التطبيق يعمل كذلك على استضافة ملفات ثابتة تدعم ملفات JSON وWebP. يمكن تثبيته من قائمة المتصفح بعد نشره عبر HTTPS. تُحفظ بيانات القراءة والتكرار والإعدادات محلياً على الجهاز. بعد الزيارة الأولى الناجحة، يحفظ عامل الخدمة النصوص والصور الأساسية للاستخدام دون اتصال؛ الصوت يحتاج الإنترنت.

## المحتوى

- 114 سورة، 6236 آية بالنص العثماني الأصلي من مشروع Tanzil عبر بيانات `quran-json`، مع فهرسة وبحث وحفظ آخر آية وتغيير حجم الخط. راجع `QURAN_DATA_LICENSE.txt`، وترخيص CC BY 3.0. لا تعدّل النص القرآني.
- 42 ذكراً في خمسة أبواب مأخوذة من بيانات زاد المسلم، مع العدد والمصدر كما جاء في المرجع. يلزم تدقيق علمي مستقل قبل أي نشر واسع أو إضافة فضائل وأحكام.
- تلاوات كاملة بروابط MP3Quran ومصادر موضحة في `quran-data/surah-reciters.json`. تختلف الروايات بين القراء؛ شاشة القرآن تعرض النص العثماني برواية حفص ولا تزامن الآيات مع الصوت في الروايات الأخرى. قد تتغير الروابط أو تتعذر حسب الاتصال.
- السمات الداكنة والفاتحة، عداد تسبيح، حفظ التقدم، وبحث السور.

## التحقق

`node --check app.js`، ومقارنة عدد السور والآيات مع بيانات الفهرس؛ ينبغي اختبار التلاوات عبر متصفح متصل بالإنترنت قبل النشر.
