# نور المسلم

تطبيق ويب عربي مستقل باتجاه RTL، بتصميم كحلي وذهبي مستوحى من واجهة زاد المسلم، مع محتوى يومي مبسط.

## المزايا

- الرئيسية مع الصلاة القادمة ومؤشرات متابعة الصلاة والأذكار والقرآن.
- أذكار الصباح والمساء والنوم وبعد الصلاة مع ورد ذكر تفاعلي.
- القرآن الكريم مع البحث، قائمة السور، ومقتطف متابعة القراءة.
- المسموع مع القراء والتشغيل والتنزيلات والمشغل المصغر.
- المسبحة الإلكترونية وشريط تنقل سفلي بأيقونات واضحة.
- صور وخطوط عربية محلية مرفقة داخل المشروع.

## التشغيل

```bash
npm start
```

ثم افتح `http://localhost:3000`.
